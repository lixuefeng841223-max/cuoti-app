# 错题管家 · 微信小程序版 使用说明

## 一、目录结构

```
miniprogram/
├── project.config.json      # 开发者工具项目配置（已预置测试 AppID）
├── app.json / app.js / app.wxss
├── sitemap.json
├── utils/
│   ├── core.js              # 核心逻辑：识别解析、自动批改、相似合并、变式题
│   └── store.js             # 数据层：本地存储、错题归档、间隔重复、统计、导出导入
└── pages/
    ├── dashboard/           # 首页：各科统计、待复习、高频错误知识点、连续学习天数
    ├── upload/              # 上传：拍照/相册/文字 → 自动识别确认 → 批改归档
    ├── library/             # 错题集：四科切换 + 知识点/题型/难度/掌握状态等筛选
    ├── review/              # 复习：隐藏答案重做、间隔重复（当天/1/3/7/14/30天）
    └── detail/              # 详情：编辑、重新作答、掌握标记、类似题、删除
```

## 二、如何运行（三步）

1. **下载安装「微信开发者工具」**（稳定版）：
   https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

2. **导入项目**：打开开发者工具 → 「导入项目」→ 目录选择本 `miniprogram` 文件夹 → AppID 使用「测试号」（已预置 `touristappid`，可先用模拟器体验）。

3. **真机预览**：点击工具栏「预览」扫码即可在手机微信中运行。
   - 测试号有功能限制（无正式发布、部分接口受限），但本应用全部功能只依赖本地存储和相机/相册，测试号即可完整体验。
   - 如需正式使用：在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册一个小程序账号（个人主体即可，免费），把 AppID 填入 `project.config.json` 的 `appid` 字段。

## 三、发布给家人使用

1. 开发者工具右上角「上传」→ 填版本号和备注。
2. 登录 mp.weixin.qq.com → 版本管理 → 开发版本 → **提交审核**。
3. 审核通过后**发布**，家人在微信中搜索小程序名称即可使用。
4. 也可以在体验阶段通过「预览」二维码或页面右上角「...」转发给家人（已内置转发能力）。

## 四、功能与网页版一致

- 四科错题管理（数学/语文/英语/科学），初始数据为空
- 拍照 / 相册 / 文字输入上传；文字自动识别题号、题型、选项、答案区段（支持「1-5 BBACA」连写）
- 自动批改：正确 / 错误 / 部分正确 / 无法判断（进入待确认）
- 错题自动归档，重复上传自动合并（错误次数累加）
- 复习：隐藏答案重做、看解析、标记掌握、举一反三变式题
- 间隔重复：当天 → 1天 → 3天 → 7天 → 14天 → 30天 → 掌握
- 首页统计：各科错题数与正确率、待复习、已掌握、高频错误知识点、近7天新增、连续学习天数

## 五、数据说明

- 所有数据保存在微信本机（`wx.setStorageSync` + 用户文件目录），不上传任何服务器。
- 换手机 / 卸载小程序会导致数据丢失；后续可在「设置」中增加导出备份功能（数据层 `store.exportData()` 已就绪，返回 JSON，可接 `wx.setClipboardData` 或云存储）。
- 若将来需要**多设备同步 / 家长端查看**，可开通微信云开发（云数据库），把 `store.js` 的读写替换为云端调用，页面层无需改动。
